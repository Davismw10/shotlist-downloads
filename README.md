# Shot List: descarregar

Aplicação para Windows para planear filmagens: projetos → cenas → planos, fichas de atores e impressão A4 (uma cena por folha). Funciona sem internet; os dados ficam só no teu computador.

## Descarregar

Vai a **[Releases](../../releases/latest)** e descarrega `Shot-List_1.1.0_x64-setup.exe`. Na mesma página está o guia de utilização (`Guia-de-utilizacao.md`).

## Instalar

1. Abre o ficheiro descarregado e segue o instalador.
2. Se o Windows mostrar "O Windows protegeu o seu PC", carrega em **Mais informações → Executar mesmo assim** (a aplicação ainda não tem assinatura digital).
3. Abre o **Shot List** pelo menu Iniciar.

Versão 1.1. O feedback é bem-vindo.

## Atualizar

Basta abrir o instalador novo: instala por cima e os teus projetos, imagens, opções e definições ficam como estão. Não é preciso desinstalar. Se desinstalares, não marques a opção de apagar os dados da aplicação.
